## ขั้นตอนในแอป
| แท็บ | เนื้อหา | อ้างอิง |
|---|---|---|
| ① น้ำหนักบรรทุก | Load takedown รายชั้น: DL (พื้น คาน ผนัง SDL น้ำหนักเสา), LL ขั้นต่ำตามการใช้งาน, ลด LL ตามจำนวนชั้น | กฎกระทรวง 2566 ข้อ 9–14, ประกาศ มท. 2567 ตาราง 2, 4 |
| ② แรงในเสา | Load case D, L, Wx, Wy, Ex, Ey (P, Mx/My ปลายบน-ล่าง, Vx, Vy) → load combination ทั้งหมด (±W, ±E) และ service combo | กฎกระทรวง ข้อ 7 (USD), ข้อ 6 (ASD); หรือ ACI 318-19 Table 5.3.1 |
| ③ หน้าตัด | P–M สองแกนด้วย strain compatibility (fiber + หมุนแกนสะเทิน), Pn,max, φ ตาม εt, ความชะลูด/ขยายโมเมนต์, แรงเฉือน, ข้อกำหนดเสริมเหล็ก, ค้นหาเหล็กยืนที่เหมาะสม | ACI 318-19 ch. 6, 10, 21, 22, 25; ประกาศ มท. 29(11), ตาราง 13 |
| ④ สรุป | รายการคำนวณ (Markdown) + CSV ดาวน์โหลดได้ | |

## เกณฑ์สำคัญ
- **ค่าตั้งต้น**: load factor 1.4D+1.7L (กฎกระทรวง ข้อ 7) คู่กับ φ ข้อ 8 — ปลอกเดี่ยว 0.70, ปลอกเกลียว 0.75, ดัด 0.90, เฉือน 0.85
  (ช่วงเปลี่ยนจาก φc ถึง 0.90 ใช้เกณฑ์ความเครียดของ ACI 318-19 21.2.2: εty ถึง εty + 0.003)
- เลือกใช้ชุด ACI 318-19 ทั้งชุด (1.2D+1.6L, φ = 0.65/0.75/0.90/0.75) ได้ — กฎกระทรวงข้อ 5 วรรคสองกำหนดให้มีเอกสารรับรองจากสถาบันที่เชื่อถือได้
- fy ที่ใช้คำนวณจำกัดไม่เกิน 550 MPa; fyt สำหรับแรงเฉือนไม่เกิน 420 MPa
- ความชะลูด: ระบบไม่เซใช้วิธีขยายโมเมนต์ 6.6.4.5 (EIeff = 0.4EcIg/(1+βdns)); M2,min ตรวจทีละแกน (6.6.4.5.4)
  ระบบเซ: ให้ใส่โมเมนต์ปลายที่ขยายด้วย δs หรือได้จากการวิเคราะห์อันดับสองแล้ว
- เครื่องหมายโมเมนต์ปลาย: ใช้ค่าจากแผนภาพโมเมนต์ภายใน (เครื่องหมายเดียวกัน = ดัดโค้งทางเดียว)
- ระยะเรียงปลอกตาม Table 10.7.6.5.2 และ Av,min บังคับเมื่อ Vu > 0.5φVc (10.6.2.1)

## ข้อจำกัด
- ไม่ครอบคลุม detailing ของเสาในระบบต้านแผ่นดินไหว (ACI 318-19 บทที่ 18), การต่อทาบ/ระยะฝัง, คอนกรีตมวลเบา
- ไม่วิเคราะห์โครงสร้าง — แรงลม/แผ่นดินไหวต้องได้จากการวิเคราะห์ภายนอก (มยผ.1311-50, มยผ.1301/1302-61)
- ผลลัพธ์เป็นเครื่องมือช่วยคำนวณ วิศวกรผู้ออกแบบต้องตรวจสอบและรับรองเอง
